V1.4.16 architecture:
- Live HDR remains exactly one current SHORT + one current LONG. Prior pairs may influence control/reliability hysteresis only; they never contribute image pixels.
- Clean HAL AE remains bootstrap-only, but no longer defines a highlight-protected dark LONG as permanent 0EV reality.
- LONG is the scene-appearance owner. A robust scene-body target uses median + p98 highlight-tail evidence; a strong HDR tail raises the 0EV body floor to 0.045 linear. The supplied V1.4.15 office failure measured 0.01462 linear median / 0.32845 p98 and therefore receives roughly +1.6EV correction at 0EV.
- LONG adapts in at most 0.20EV live steps. Brightness remains -5.0..+2.0EV and biases LONG appearance, not bracket size.
- SHORT independently owns highlight insurance. Bracket widening needs two consecutive stable meaningful-clipping samples; release needs three samples, preventing threshold chatter.
- Every live SHORT/LONG request set carries an immutable exposure-generation ID. HdrGlView publishes only exact same-generation pairs, and CameraController rejects statistics from retired generations.
- Live SHORT authority requires two consecutive temporally stable 32x24 samples. If normalized SHORT highlight brightness/chroma changes while LONG remains stable, fusion falls back to LONG until stability returns.
- Known 50/60-Hz lighting never deliberately crosses below the safe 10ms/8.333333ms integration period merely for more HDR headroom. Unknown/PWM preserves clean-AE LONG integration and keeps SHORT on LONG integration while using ISO headroom first.
- SHORT-to-LONG overlap calibration is one scalar luminance/exposure calibration, not independent R/G/B gains. This prevents exposure calibration from manufacturing hue shifts.
- Highlight fusion is coherent RGB, not independent per-channel recovery. If any SHORT channel approaches the processed ceiling, SHORT is rejected for that highlight.
- A neutral multi-channel clipped LONG suppresses weak/moderate SHORT ISP tint, so a white car reflection/ceiling light cannot become pink/orange merely because SHORT and LONG differ.
- LONG remains full RGB owner everywhere outside genuinely lost highlights. A clean stable white clip is intentionally preferred to pink/orange/PWM/blotchy recovery.
- Saved JPEG fusion mirrors scalar calibration, coherent SHORT safety, neutral-highlight protection and LONG-first tone ownership.
- AUTO and MANUAL SAFE retain the same adaptive SHORT intelligence; MANUAL keeps user LONG intent with its existing extra headroom policy.
- Orientation, FOV, cadence, DNG, sRGB, noise/edge ownership, frozen still pair, stable signing and capture protections are inherited unchanged.
