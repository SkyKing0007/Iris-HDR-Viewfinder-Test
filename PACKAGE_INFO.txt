V2.38 CORRECTION CONTRACT
1. JpegFusion keeps the successful V2.37 whole-frame gradient registration as the normal solution but audits it against a 5x4 spatially distributed tile consensus. A valid distributed consensus can replace a materially disagreeing whole-frame hypothesis; weak/non-distributed consensus leaves V2.37 unchanged.
2. Local-flow alpha now records direct ownership: alpha=255 only where that cell's own forward/backward cycle-validated residual survived the strict existing gate. Filled/inferred cells remain available for coarse topology continuity but carry alpha=0 and cannot warp final SHORT RGB.
3. hdr_display validates the unclamped SHORT coordinate before sampling. A 1.25-pixel interpolation-safe source margin is mandatory; invalid requests fail closed instead of clamping an off-frame warp to border pixels.
4. Local residual displacement is applied only when direct local confidence is strong. Unsupported/inferred locations use exactly the stable global registration residual of zero rather than borrowing a neighboring local warp.
5. Final non-clipped effective-loss recovery requires full-resolution static correspondence: real source bounds, direct local geometry and loose same-scene radiometric agreement. Moving/disoccluded content therefore fails closed to immutable LONG.
6. Physical hard clipping remains eligible for HDR recovery because LONG has genuinely lost information, but real SHORT source bounds remain mandatory. V2.38 does not claim that two different moving moments can be perfectly reconstructed; it prevents uncertain geometry from becoming a general source owner.
7. Saved RAW effective-loss analysis adds a universal 1.5px microstructure class. SHORT structure must exceed five times its physical local sigma, materially exceed LONG at the same location, and have direct local geometry. This is source-evidence based and semantic-independent; no sharpening or frequency blending is introduced.
8. Source ownership remains complete RGB from one real frame per final highlight/detail pixel. LONG remains the default clean body; SHORT only owns where physical/effective information loss is proven under the above geometry rules.
9. raw_chroma_dealias uses the existing physical RAW saturation bit to identify only the immediate saturation transition halo. In that halo, unsupported chroma can move toward a local unsaturated, same-luminance-side estimate; ordinary unsaturated colored edges retain the V2.36/V2.37 local chroma behavior.
10. Saturation-edge cleanup preserves center luminance, uses no distant hue donor and introduces no blanket/global desaturation.
