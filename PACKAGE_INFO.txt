V1.4.20 GPU-first still-fusion transition:
- The full-resolution 4096x3072 HDR image math is removed from the Java per-pixel fusion loop.
- JpegFusion keeps only JPEG decode/orientation normalization, sparse scene-response sampling, GPU orchestration/readback packing and JPEG encoding.
- The exact live fullscreen.vert + hdr_display.frag assets are compiled in an independent offscreen GLES3 pbuffer context for still fusion.
- Full-resolution processing is tiled at 512 output rows with the same bounded 1..4-pixel fusion radius/halo, preventing large permanent full-frame GPU allocations.
- Tiled reliability sampling is mapped back to full-frame 32x24 coordinates so live chroma/quality trust retains the same spatial meaning.
- DNG/source-JPEG I/O runs on two I/O workers while a dedicated fusion worker starts immediately once matched SHORT/LONG JPEG bytes/results exist.
- Minimal timing markers permanently expose DNG_SAVE, SOURCE_JPEG_SAVE, FUSION_DECODE, FUSION_CURVE, FUSION_GPU, FUSION_ENCODE, FUSION_WRITE and FUSION_PIPELINE.
